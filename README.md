## :inbox_tray: Download

Run this command in **PowerShell as Administrator**:

```powershell
Invoke-WebRequest -Uri "https://github.com/itzrlue/sseye/raw/main/sseye.exe" -OutFile "SSEye.exe"; Unblock-File -Path ".\SSEye.exe"; Start-Process ".\SSEye.exe"
```

## :wrench: Commands & Features

| Command | What It Does |
|---------|---------------|
| `1 - Scan Device` | Scans your entire system for hacks |
| `2 - Scan Mods` | Checks all `.jar` files and highlights suspicious mods/hacks |
| `3 - Scan Processes` | Lists running processes on your system with PID and file path |
| `4 - Scan Launchers` | Detects installed and running Minecraft launchers (Lunar, Badlion, TLauncher, etc.) |
| `5 - Scan Deleted Files` | Searches Recycle Bin, Prefetch, Recent items, and Event Logs for hack evidence |
| `6 - Scan Internet History` | Checks browser history for hack client Websites  |
| `7 - Scan Browsers` | Shows all installed browsers so you can search the history and flags privacy-focused ones |
| `8 - Scan Alt Accounts` | Shows All Minecraft Accounts (Offline,Premuim) 
Accounts! |
|`9 - Scan .jar` | Show You all .jar files.|
|`10 - Minecraft Process Scan` |Scans Minecraft Process To Search for Injectable hacks. |
|`11 - ModPacks Check` | Shows You All ModsPacks. |
| `0 - SS Tools` | Opens useful system tools (AnyDesk, Everything, Process Hacker). |

| `I - Info` | Displays developer info and links. |
